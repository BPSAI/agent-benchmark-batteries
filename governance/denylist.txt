# Deny-list for the content scanner (see governance/check_denylist.py).
#
# One regex per non-comment, non-blank line. Matching is case-insensitive.
# Every tracked file in this repo is scanned against every pattern below,
# with no exemptions, including this file and the scanner script.
#
# Two patterns below use a single-character bracket in the middle of a
# plain word (e.g. `intern[a]l`) so the pattern's own text here does not
# match itself -- do not "simplify" that spelling.

# --- infra shapes ---
\.azurecr\.io\b
\bkv-[a-z0-9-]+\b
\.intern[a]l\b

# --- path shapes ---
/home/[a-zA-Z0-9_.-]+/
\.[a-zA-Z][a-zA-Z0-9_-]*/histor[y]\b

# --- credential-shaped strings ---
sk-ant-[a-zA-Z0-9-]+
sk-proj-[a-zA-Z0-9-]+
AKIA[0-9A-Z]{16}
ghp_[a-zA-Z0-9]{36}
gho_[a-zA-Z0-9]{36}
